# 阿里云容器镜像服务Web登录说明 / Aliyun Container Registry Web Login Instructions

## 中文说明

### 如何通过网页登录阿里云容器镜像服务

要通过网页访问阿里云容器镜像服务仓库地址：`https://shgbit-rd-registry-ee-r1n2xs-registry.cn-shanghai.cr.aliyuncs.com/`

#### 访问步骤：

1. **访问阿里云容器镜像服务控制台**
   - 打开浏览器，访问：[https://cr.console.aliyun.com/](https://cr.console.aliyun.com/)
   - 使用您的阿里云账号登录

2. **选择地域**
   - 在控制台中选择对应的地域：**华东1（上海）** (cn-shanghai)
   
3. **查看镜像仓库**
   - 在左侧导航栏中，选择"镜像仓库"
   - 您可以看到您有权限访问的所有仓库列表
   - 找到对应的企业版实例：`shgbit-rd-registry-ee-r1n2xs`

4. **访问企业版实例**
   - 点击实例名称进入实例详情页
   - 在这里您可以：
     - 查看仓库列表
     - 管理镜像标签
     - 查看镜像层信息
     - 配置访问权限
     - 查看操作日志

#### 注意事项：

- 确保您的阿里云账号具有访问该容器镜像服务实例的权限
- 如果无法访问，请联系管理员授予相应的 RAM 权限
- 企业版实例需要有相应的订阅或购买

## English Instructions

### How to Access Aliyun Container Registry via Web Browser

To access the Aliyun Container Registry at: `https://shgbit-rd-registry-ee-r1n2xs-registry.cn-shanghai.cr.aliyuncs.com/`

#### Access Steps:

1. **Access Aliyun Container Registry Console**
   - Open your web browser and visit: [https://cr.console.aliyun.com/](https://cr.console.aliyun.com/)
   - Log in with your Aliyun account credentials

2. **Select Region**
   - In the console, select the corresponding region: **China East 1 (Shanghai)** (cn-shanghai)
   
3. **View Image Repositories**
   - In the left navigation menu, select "Image Repository"
   - You will see a list of all repositories you have permission to access
   - Find the corresponding Enterprise Edition instance: `shgbit-rd-registry-ee-r1n2xs`

4. **Access Enterprise Edition Instance**
   - Click on the instance name to enter the instance details page
   - Here you can:
     - View repository list
     - Manage image tags
     - View image layer information
     - Configure access permissions
     - View operation logs

#### Important Notes:

- Ensure your Aliyun account has permission to access this Container Registry instance
- If you cannot access it, contact your administrator to grant the appropriate RAM permissions
- Enterprise Edition instances require a corresponding subscription or purchase
